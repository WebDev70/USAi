# Raw Data

Store original inputs here.

Examples:

- User-provided documents.
- Exported conversations.
- Logs.
- Screenshots or OCR text.
- Requirements documents.
- Example inputs and outputs.

## Rules

- Preserve original filenames when practical.
- Do not edit raw data in place.
- Record provenance in a nearby note when the source is not obvious.
- Avoid storing secrets, credentials, private keys, or regulated data unless the project has approved controls.
