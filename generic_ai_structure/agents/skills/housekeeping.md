# Skill: Housekeeping

Use this skill at the end of every task and during periodic maintenance sweeps.

## Purpose

Housekeeping keeps the project easy to audit. It removes ambiguity about what is final, what is temporary, and what still needs follow-up.

## Per-task checklist

- Final artifacts are in the correct folder.
- Temporary files, scratch notes, and one-off generated outputs are removed or clearly marked.
- Task trace links to checks, scorecards, and follow-ups.
- Deferred work is recorded in the follow-up log or target project backlog.
- Documentation, prompt indexes, data indexes, and eval indexes are updated when new artifacts are added.
- No secrets, private tokens, or sensitive data were copied into traces or examples.

## Periodic sweep checklist

- Close or re-triage stale follow-ups.
- Archive obsolete traces according to project retention rules.
- Verify prompt files still reference current evals.
- Verify processed data still references raw sources.
- Review scorecard trends for repeated weak categories.
- Remove unused templates or consolidate duplicates.

## Outputs

- Housekeeping pass/fail decision.
- List of removed or moved temporary artifacts.
- List of stale follow-ups and decisions.
- Index or README updates made.

## Blocking failures

- Final result depends on an untracked temporary artifact.
- Deferred blocking work is not recorded.
- Sensitive content is found in examples, traces, logs, or datasets.
- New artifacts are not discoverable from the relevant README or index.
